# 🚀 Add this library to GitHub

1. Unzip `PowerBI_Business_Decisions_GitHub.zip`.
2. Create a repository such as `power-bi-for-business-decisions`.
3. Upload **all extracted contents** to the repository root, keeping `assets/`, `chapters/` and `practice/` in their existing locations.
4. Commit the files. GitHub renders the root `README.md` as the learning hub.
5. Link the repository URL from the **Power BI for Business Decisions** card on your portfolio.

The complete folder is needed for the banner, chapter links and practice references. Pasting only the README does not include those resources.

This is a GitHub study library, not an embedded live Power BI report. The charcoal, amber and blue design uses GitHub-supported images, badges, tables, callouts and expandable answers. GitHub controls the body font and most text colouring.

All business scenarios use fictional PayBridge. Describe them as learning examples; do not present the fixture as a real employer's data or a completed production project.
